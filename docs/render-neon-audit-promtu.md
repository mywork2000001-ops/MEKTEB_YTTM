### D5 подробно — бэкап в Google Drive (запрос пользователя 18.10)

Папка: «Backup silmek olmaz» (`1qWO3P5bThIBcRufQjTcxpBd1EuhOCVKy`), владелец mywork2000001@gmail.com.
⚠️ **Проверено 18.10: доступ «все, у кого есть ссылка — читатель».** В бэкапе будут ФИО, оценки, сканы учеников —
**до первого бэкапа доступ закрыть** (Поделиться → Общий доступ → «Доступ ограничен»). Пока доступ открыт — не загружать.

**Решение 18.10 (пользователь: «раз в неделю или в месяц — на твоё усмотрение»): раз в неделю**, воскресенье 03:00 Баку;
недельные хранятся 8 недель, первая копия месяца (`-ayliq`) — навсегда. Короткий срок покрывает PITR Neon.
**Сделано (не закоммичено, не запушено):** `.github/workflows/db-backup.yml`, `backend/tools/backup_to_drive.py`.
Ограничение `drive.file`: приложение видит только СВОИ файлы → при первом запуске скрипт создаёт папку
«Müəllim köməkçisi – baza nüsxələri (şifrəli)», пользователь перетаскивает её в «Backup silmek olmaz», id → секрет.
OAuth-клиент Google Cloud перевести в «In production» (в режиме Testing refresh-token живёт 7 дней).

Схема (GitHub Action, не сервер Render: там 512 MB и он спит ночью):
1. Ночью 03:00 Баку (`cron: '0 23 * * *'` UTC) — `pg_dump` (клиент той же major-версии, что Neon) по секрету
   `NEON_BACKUP_URL` (отдельная роль только на чтение) → `muellim_YYYY-MM-DD.sql.gz` (вместе с `file_blobs`).
2. Шифрование `gpg --symmetric` паролем из секрета `BACKUP_PASSPHRASE` (пароль пользователь хранит у себя) — даже при
   случайном открытии папки файл нечитаем.
3. Загрузка в папку через Drive API: OAuth refresh-token аккаунта mywork2000001 (получить через `backend/tools/gdrive_auth.py`,
   секреты `GDRIVE_CLIENT_ID/SECRET/REFRESH_TOKEN`), scope `drive.file`.
4. Хранение: ежедневные — 30 дней, бэкап 1-го числа — навсегда (папка «silmək olmaz»; старые дневные удаляет сам job).
5. Job падает при ошибке → GitHub шлёт письмо. Раз в месяц — пробное восстановление в отдельную Neon-ветку
   (`tools/restore_backup.py` / `pg_restore`), сверка числа строк ключевых таблиц.
Учесть: каждый дамп = сетевой трафик Neon (размер БД ×1 в сутки) — посмотреть размер в Neon перед включением.
