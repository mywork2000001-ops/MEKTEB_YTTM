# Анонимный опрос учеников о работе учителя (Həsənov Fərid): ссылка (WhatsApp, QR), приложение ученика, аналитика

> Дата: 04.10.2026. Требования учителя (в порядке поступления):
> 1. «Профессиональный и личностный опрос среди учеников о моей работе по всем критериям, в виде HTML-ссылки; данные
>    хранятся в приложении, чтобы я мог их обработать».
> 2. «Могу отправлять в WhatsApp, а ученик может участвовать в опросе и в приложении (опрос обновляется в приложении
>    ученика каждую рабочую неделю)».
> 3. «Когда ученик открывает приложение, появляется приглашение участвовать в опросе. Это не должно утомлять ученика».
> 4. «В WhatsApp-группу — по ссылке либо полный опрос, либо короткий, меняющийся каждый раз».

## 0. Роль и цель

Ты — ведущий инженер этого проекта (FastAPI + SQLAlchemy + Alembic, React + Vite + TypeScript) и специалист по
педагогическим измерениям (обратная связь учеников, шкалы Лайкерта, pulse-опросы, матричная выборка, анонимность).

**Цель.** Учитель создаёт опрос из готового профессионального шаблона. Ученики проходят его анонимно двумя путями:
- по **публичной ссылке** `/s/{token}` — WhatsApp (личные сообщения и группа), QR на листе;
- **в своём приложении**, в разделе «Sorğular». Здесь же появляется мягкое приглашение.

Ответы хранятся в БД. Учитель видит аналитику по критериям, сравнение классов, динамику по неделям и волнам, открытые
ответы и AI-резюме. Есть печать/PDF и CSV для Excel.

Весь интерфейс **на азербайджанском**.

НЕ НАРУШАЙ существующие правила:
- `ws_cond` / `school_id`: школа и fərdi məkan не смешиваются;
- учитель видит только свои опросы (чужой → 404);
- ученик не видит результатов (staff → 403);
- в `AuditLog` попадает только «создан / открыт / закрыт / удалён», ответов там нет.

## 1. Принципы (обязательно)

1. **Настоящая анонимность.**
   - В `SurveyResponse` нет `student_id`, имени, IP и user-agent. Дата хранится с точностью до дня.
   - Защита от повтора — только хеши `sha256(secret | survey | источник | период)` в отдельной таблице `SurveyDedup`.
   - Источники хеша: httpOnly-cookie устройства, токен устройства из localStorage, `user_id` (если ученик залогинен).
2. **k-анонимность.**
   - Любой срез (весь опрос, класс, неделя, волна) показывается только при ≥ `min_group` ответов (по умолчанию 5).
   - Открытые ответы идут в случайном, но стабильном порядке, без дат.
3. **Не утомлять ученика.**
   - Короткий режим: ~8 вопросов, 1–2 минуты, один экран без отдельного вступления.
   - Приглашение в приложении не блокирует экран, появляется через 2,5 с после загрузки и не чаще 1 раза в день на опрос.
   - Кнопка «Sonra» откладывает приглашение до завтра. После ответа приглашение не показывается до новой недели.
4. **Сравнимость.** После первого ответа вопросы и тип опроса (разовый / еженедельный) заморожены. Изменения — только
   через «Yenidən keçir» (новая волна, вопросы копируются, `root_id` + `wave`).

## 2. Модель данных (миграция `d7f3a1c5e9b2`, ревизия-родитель `c5e7a9b1d3f4`)

| Таблица | Поля |
|---|---|
| `surveys` | owner_id, school_id, title, description, template_key, sections[{key,title}], status (draft/open/closed), opens_at, closes_at, min_group, **repeat** (once/weekly), **in_app**, **pulse**, root_id, wave, Archivable |
| `survey_questions` | survey_id, key (A1…, overall, nps), section, order, kind (likert5/scale10/single/multi/text), text, options, required, reverse |
| `survey_links` | survey_id, token, class_id NULL, label, **mode** (auto/full/short), active |
| `survey_responses` | survey_id, link_id, **period** («2026-W41» или «once»), submitted_on (день), answers, hidden[qid] |
| `survey_dedup` | (survey_id, hash) |
| AI-резюме | существующая `ai_reviews`, scope=`survey`, key=`survey:{id}:{link}:{period}` |

## 3. Опросник `teacher_feedback_v1`

Лайкерт 1–5: «Tamamilə razı deyiləm … Tamamilə razıyam». Обратные вопросы (R) считаются как 6 − x.

**Шкала:**
- A. Fənn bilgisi və izah (A1–A5, A5 R)
- B. Dərsin təşkili və metodika (B1–B5)
- C. Qiymətləndirmə və geri bildirim (C1–C4)
- D. Ünsiyyət və münasibət (D1–D6, D6 R)
- E. Motivasiya və inkişaf (E1–E4)
- F. İntizam və peşəkar davranış (F1–F4)

**Другие блоки:**
- G. `overall` — оценка 1–10; `nps` — 0–10 (промоутеры 9–10, критики 0–6).
- H. Три открытых вопроса (≤ 1000 символов, HTML вырезается).
- X. Необязательный блок «о себе»: класс, посещаемость.

Учитель может менять вопросы, разделы, типы и порядок — только пока нет ответов.

## 4. Режимы прохождения

**Набор вопросов в коротком режиме** (`pulse_pick`):
- из каждого раздела A–F один лайкерт-вопрос, по очереди;
- `overall` — всегда;
- `nps` — раз в 4 недели или варианта;
- один открытый вопрос по очереди;
- дополнительные вопросы учителя типа scale/single/multi.

За 4–5 недель или вариантов охватывается вся анкета.

| Где | Режим | Как меняется короткий набор | Повтор |
|---|---|---|---|
| Еженедельный опрос, `pulse=true` (по умолчанию) | короткий | по ISO-неделе (Баку, UTC+4): каждую неделю новые вопросы | 1 раз в неделю |
| Еженедельный опрос, `pulse=false` | полный | — | 1 раз в неделю |
| Разовый опрос | полный | — | 1 раз |
| Ссылка `mode=full` | полный всегда | — | по типу опроса |
| Ссылка `mode=short`, еженедельный опрос | короткий | по неделе | 1 раз в неделю |
| Ссылка `mode=short`, разовый опрос | короткий | **у каждого ученика свой вариант** (матричная выборка); вариант хранится в localStorage, чтобы при перезагрузке набор не менялся | 1 раз |

**Ссылки.** Для одного опроса можно сделать несколько ссылок — например, в WhatsApp-группу «полная» и «короткая».
Режим ссылки можно поменять в любой момент. Валидация ответа идёт только по вопросам, реально выданным ученику.

## 5. Публичная страница `/s/{token}` (без входа и без меню)

- `GET /api/public/surveys/{token}?v=` → заголовок, учитель, класс, неделя, режим, variant, вопросы (без флага reverse),
  `done` (если залогинен и уже ответил).
  - 404 — ссылка неактивна;
  - 410 — опрос закрыт или вне окна дат.
- `POST …/responses {answers, device, variant}`:
  - 400 — не отвечен обязательный вопрос или значение вне шкалы;
  - 409 — «Siz artıq cavab vermisiniz (bu həftə)»;
  - 429 — rate limit по токену ссылки (IP не хранится).
- **Длинная анкета:** вступление с текстом об анонимности → разделы по одному на экран («Geri / İrəli») → «Göndər» →
  «Təşəkkür edirik!».
- **Короткая (≤ 10 вопросов):** один экран, строка «🔒 Anonim · N sual · ~1–2 dəq.», прогресс по числу отвеченных.
- Черновик хранится в localStorage (`try/catch`). Кнопки ≥ 44 px, работает на 360 px, тёмная тема, видимый фокус.

## 6. Приложение ученика

- `GET /api/portal/surveys` → открытые опросы с `in_app=true` от учителей, которые ведут уроки у класса или группы
  ученика. Поля: `questions`, `period`, `done` (хеш ученика за текущий период).
- `GET/POST /api/portal/surveys/{id}` — тот же `SurveyForm`. Ответ записывается в ссылку класса (создаётся
  автоматически) — нужно для сравнения классов. Хеш ученика общий со ссылкой: через WhatsApp-ссылку повторить нельзя.
- Раздел «Sorğular» (меню ученика): карточки «N sual, ~M dəq.», статус «Bu həftə cavab verdiniz».
- **SurveyNudge** (в `Layout`, только у ученика): небольшая карточка внизу справа (на телефоне — над tab-bar) с текстом
  «Müəlliminiz haqqında fikriniz · N sual, ~M dəq. · anonim» и кнопками «Sonra / Başla»; правила показа — в п. 1.3.

## 7. Раздел учителя «Şagird sorğusu» (`/surveys`)

1. **Список и архив.** В карточке: статус (Qaralama / Açıq / Planlaşdırılıb / Bağlı / Arxivdə), тип, число ответов,
   число ссылок, готовность результата.
2. **Создание.**
   - Название и текст обращения к ученикам.
   - Тип: Birdəfəlik или Hər həftə. Для еженедельного — «Qısa həftəlik sorğu» (по умолчанию включено).
   - «Tətbiqdə göstər», блок «о себе».
3. **Paylaş.** Для каждой ссылки:
   - URL;
   - режим «Avtomatik / Tam anket / Qısa, hər dəfə dəyişir» с подсказкой, сколько вопросов и как меняются;
   - **«WhatsApp-da göndər»** (`https://wa.me/?text=` с готовым текстом: анонимно, N вопросов, ~M минут, ссылка);
   - «Paylaş…» (Web Share API), «Linki kopyala», «Mətni kopyala», «QR çap et» (A4: QR 110 мм + инструкция), «Deaktiv et».
   - Добавить ссылку класса (`own_assignment`) или общую ссылку для WhatsApp-группы с выбранным режимом.
4. **Suallar.** Редактор: разделы, текст, тип, обязательность, обратный вопрос, варианты, min/max, порядок.
   После первого ответа — только просмотр.
5. **Parametrlər.** Окно дат, порог анонимности 3–30, тип (до первого ответа), короткий режим, «в приложении».
6. **Nəticələr.** Фильтры «Hamısı» / ссылка-класс / неделя.
   - KPI: ответы, общий балл, NPS, средний индекс.
   - Индекс по критериям A–F: шкала 1–5, процент согласных. Цвет: ≥ 4,3 очень сильно; 3,8–4,3 сильно; 3,2–3,8 зона
     роста; < 3,2 внимание.
   - Сильные стороны и зоны роста: топ-3 и анти-топ-3. У обратного вопроса пояснение «şagirdlər razı deyil, bu yaxşıdır».
   - Распределение 1–10 и 0–10; stacked-bar по каждому вопросу.
   - Таблицы «Siniflər / Həftələr / Dalğalar» с ▲▼ изменениями.
   - Открытые ответы: поиск и «Gizlət» (скрыть из отчёта, не удаляя).
   - **AI-рецензия** (`ai.py`, ключ учителя): резюме, сильные стороны, зоны роста, темы открытых ответов с тоном,
     измеримые рекомендации на 2–6 недель, предупреждение о малой выборке. В модель идут только агрегаты и анонимные тексты.
   - «Çap / PDF» (`print.ts`, отметка «Daxili istifadə üçün»), «Excel (CSV)» (UTF-8 BOM, «;», строки перемешаны,
     скрытые тексты не попадают). CSV и AI недоступны ниже порога.
7. **Архив.** Опрос можно архивировать и восстанавливать. Удаление навсегда — только из архива и только после ввода
   названия (удаляются ответы, хеши, ссылки и AI-резюме).

## 8. Тесты (`backend/tests/test_api_surveys.py`)

- Публичная ссылка: черновик → 410; закрыт → 410; неактивна → 404.
- Обязательные вопросы и шкала → 400; повтор с того же устройства → 409; HTML вырезается.
- Порог: при 4 ответах скрыто (CSV → 409), при 5 видно.
- Расчёты: обратный вопрос (6 − x), индекс раздела, NPS.
- В `SurveyResponse` нет полей, указывающих на ученика.
- Права: ссылка класса только на свой урок; чужой учитель / другая школа → 404; ученик → 403.
- Вопросы заморожены после первого ответа; волна 2 копирует вопросы; удаление только из архива и с подтверждением.
- **Еженедельный опрос в приложении.**
  - Короткий набор: 8 вопросов, разделы A–F + overall; на следующей неделе другие лайкерт-вопросы.
  - Повтор в той же неделе → 409, в том числе через публичную ссылку. Новая неделя снова доступна.
  - Динамика по неделям (≥ 5); тип не меняется после ответов; `pulse=false` → 35 вопросов; `in_app=false` → не виден.
- **Режимы ссылок:** full = 33, short = 8–9; разные варианты дают разные наборы. Короткий ответ принимается по короткой
  ссылке и отклоняется по полной; режим ссылки можно сменить.
- AI: ниже порога → 409; в контекст модели попадают анонимные тексты; последняя рецензия кэшируется.
- Фронтенд: `npm run build` (`tsc -b`); проверка в браузере (`/s/{token}` длинная и короткая, Paylaş, Nəticələr).
