# Методический аудит «Müəllim köməkçisi» — 24.10.2026

Метод: карта всех разделов учителя и ученика (Layout.tsx, App.tsx, 40+ модулей backend), чтение правил оценивания в коде
(`domain/rules.py`, `domain/scoring.py`, `exam_logic.py`, `plan_tests.py`, `timing.py`, `levels.py`, `certificates.py`),
выборочная перепроверка утверждений в коде, сверка с прошлыми аудитами (`docs/muellim-auditi.md`, `sagird-auditi.md`,
`jurnal-auditi.md`, `docs/audit/icra-2026-10-2*.md`). Взгляд — методиста-математика, школа Азербайджана (KSQ/BSQ, DİM).
Пометки: **Ф** — факт в коде (с файлом), **Н** — наблюдение.

## 1. Что сделано методически хорошо (оставить как есть)
| Область | Почему хорошо |
|---|---|
| KSQ/BSQ и полугодие | Шкала 0–30/31–60/61–80/81–100, полугодие = KSQ×0,4 + BSQ×0,6, год = среднее полугодий; запреты: KSQ вне полугодия, 2 BSQ в полугодии (`rules.py`, аудит 29.09) |
| Журнал | Оценка отсутствующему запрещена; ДЗ проверяется только у присутствовавших и только прошлых дней; формативная оценка заблокирована в день KSQ/BSQ |
| Пересдача | Засчитывается лучший результат (основной/дополнительный), выбор источника балла online/paper/max/manual (`exam_logic.py`) |
| Апелляции | По вопросу, со сроком; принятая апелляция исправляет всем, у кого был тот же вопрос |
| Вес вопросов | 100-балльная шкала с учётом типа и сложности; сложность уточняется по статистике (≥10 ответов) — честнее «1 вопрос = 1 балл» |
| Пробные экзамены | Штраф DİM за неверный ответ, пустой не штрафуется — как на реальном экзамене |
| Дифференциация | Группы уровней с гистерезисом (переводы только предлагаются), inkişaf/tərəqqi с входной/выходной диагностикой, `slow_plan` (двухлетний темп для слабого класса), fərdi 2×45 |
| Учёт прохождения | Статусы keçildi/təkrar/qismən/gecikir и прогноз по темпу (`progress.py`) |
| Тетради | AI ставит статус и комментарий, но не оценку — оценка остаётся за учителем |
| Отчёт ученика | Неопубликованный балл скана скрыт, среднее по классу показывается только при 5+ результатах (защита от сравнения «один на один») |

## 2. Проблемы и мои решения
| № | Проблема | Ф/Н | Решение (принято) | Приоритет |
|---|---|---|---|---|
| M1 | Тест без срока закрывается «в 2100 году», а ответы и разбор показываются только **после закрытия** → ученик может вообще не увидеть разбор ошибок | Ф `plan_tests.py:440`, `timing.py` NO_DEADLINE | Для тематических (формативных) тестов **без срока** показывать ответы и izah **сразу после сдачи** (`after_submit`). Тесты со сроком и KSQ/BSQ/sınaq — как сейчас (`after_close`), чтобы не было списывания в классе | P1 |
| M2 | В «Sual təhlili» видно только % верных; какой неверный вариант выбирали — не видно, хотя ответы хранятся (`TaskAttempt.answers`) | Ф | Добавить **анализ дистракторов**: по каждому вопросу — распределение выбранных вариантов (A–E, пусто), подсветка «популярной ошибки» (≥30% класса выбрали один и тот же неверный вариант). Учителю это сразу показывает типичную ошибку для разбора на уроке | P1 |
| M3 | Онлайн-тест сдаётся один раз; повтор только после ручного сброса → нет «работы над ошибками» | Ф `portal.py:379`, `tasks.py:507` | **Попытка «Səhvlər üzərində iş»**: после показа разбора ученик может один раз пройти только свои неверные вопросы (те же или аналоги из банка по той же теме). Оценка в журнале **не меняется** (остаётся первая попытка), результат идёт в «освоение темы» и видна учителю | P1 |
| M4 | Описание `auto_tests.py` (45 мин, закрытие на следующий день в 22:00) расходится с настройками по умолчанию `Opts()` (без таймера, без срока) — учитель не знает, что реально получит ученик | Ф `auto_tests.py:4` vs `plan_tests.py:58` | Правда — в коде (Opts по умолчанию, решение 19.10). | M6 | Формативный онлайн-тест оценивается суммативной шкалой KSQ (30% → «2») | Ф `tasks.py:48` | Добавить **настройку класса «Формативная шкала»** (пороги 3/4/5). По умолчанию = текущая шкала KSQ (поведение не меняется, пока учитель сам не поменяет). Рядом с оценкой показывать уровень освоения словами (yüksək/orta/aşağı по `rules.py:7-8`) | P2 |

| M12 | Риск-факторы бинарные («всё или ничего») | Ф `rules.py:83` | Плавная шкала 0..1 для каждого фактора (линейно между порогами), веса прежние. Цвета жёлтый/красный — те же пороги | P3 |

## 3. Что не трогать (методически обосновано)
- Не делать автоматических переводов между группами уровней — только предложение учителю (гистерезис 5 уже есть).
- Не давать AI ставить оценки за тетради.
- Не менять шкалу KSQ/BSQ и формулу полугодия — это официальные правила.
- Не открывать ответы KSQ/BSQ/sınaq сразу после сдачи (M1 касается только формативных тестов без срока).
